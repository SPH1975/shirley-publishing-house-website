SHIRLEY PUBLISHING HOUSE — PRIVATE CONTENT MANAGER

ADMIN ADDRESS
https://shirleypublishinghouse.com/admin/

SIGN IN
The content manager uses Netlify Identity and Git Gateway. Registration must remain
Invite only. Use the administrative email invited in Netlify. If the password is
forgotten, use the Forgot password link in the sign-in window.

WHAT THE ADMIN CAN MANAGE
1. Publications and cover images.
2. Journals, journal covers, and full-issue PDFs.
3. Every individual journal article and its PDF.
4. Website page headings and introductions.
5. Publishing services.
6. Contact, brand, and footer information.
7. Uploaded media through the Media area.

UPLOAD A JOURNAL ARTICLE
1. Open Journal Article Archive.
2. Select New Journal Article.
3. Choose the journal and enter the article metadata.
4. Enter the volume, issue, date range, publication date, and page range.
5. Upload the final PDF in Article PDF.
6. Select Publish.

The publish action commits the new JSON record and PDF to GitHub. Netlify then runs
the content build and deploys the updated archive.

REMOVE A JOURNAL ARTICLE AND PDF
1. Open Journal Article Archive and select the article.
2. Use Delete entry and confirm the deletion.
3. Open Media, locate the matching PDF, and delete it if the file should also be
   removed from the repository.

Deleting an article entry removes it from the public archive. The PDF is deliberately
managed separately so a file is not destroyed accidentally.

UPLOAD OR REMOVE OTHER FILES
Use Media for images and PDFs that are not attached while editing an entry. Files are
stored in assets/uploads. Remove only files that are no longer used by a publication,
journal, article, or page.

PUBLICATIONS, JOURNALS, PAGES, SERVICES, AND SETTINGS
Open the matching section, create or edit an entry, and select Publish. Delete entry is
available for folder-based content such as publications, journals, articles, and
services.

HOW CHANGES GO LIVE
Each admin action creates a GitHub commit on main. Netlify automatically rebuilds the
generated website data files and deploys them. HTML, generated data, and uploaded files
are configured to revalidate so visitors receive the current version without manual
cache-version edits.

SECURITY
- Keep Netlify Identity registration set to Invite only.
- Keep Git Gateway enabled for the connected GitHub repository.
- Invite only trusted administrators.
- Never place GitHub or Netlify tokens in admin files or browser storage.
- Do not share passwords, one-time codes, or recovery links.

LOCAL VALIDATION
Run npm run build after manually changing content. The build must complete before the
change is published.
